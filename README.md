One funny line, whole on its own: My fitness tracker congratulated me on 10,000 steps — 9,800 of them were just me pacing around looking for my phone. The program in `main.py` writes that single line (116 characters) to `entry.txt` in the output directory, after checking it fits the 1–200 character gate.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
